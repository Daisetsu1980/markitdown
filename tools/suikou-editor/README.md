# 推敲卓（すいこうたく）

『スポーツは何のためにあるのか――不合理な遠回りの哲学』の草稿を仕上げるための、推敲専用エディタです。
Claude Artifact として公開して使います（`index.html` の一枚もの）。

公開先: https://claude.ai/artifact/PjsxaeZAkhhhzrHmLjTJnc

## できること

- **自動構造化** — 本文を貼り付けると、章（`第N章`／プロローグ／エピローグ／あとがき）と節に分け、目次を作る。
- **チェック** — 節ごとに要修正箇所を拾い、七つの種別に色分けして本文に印を付ける。
  論証・身分・階層・接続・修辞・語・文末。凡例のボタンで種別ごとに表示を切り替えられる。
- **修正案** — 本文を選ぶと、その範囲の書き換え案が三つ出る（控えめ／現在の設定／踏み込んだ直し）。
  押すとその場で置き換わる。`元に戻す` で戻せる。
- **効かせ具合** — 1〜4（点検／控えめ／標準／組み直し）。拾う範囲と書き換えの踏み込みが変わる。
- **見出しを検討** — 新書の見出しの基準（要約型を避け、問いのかたちに立てる／簡潔な名詞句・疑問文・短い平叙文）で三案を出す。
- **原文** — 節ごとに草稿の原文と比べ、必要なら戻す。
- **書き出す** — 全文を Markdown で保存する。

## 判断の基準

`CRITERIA` 定数に、七つの種別の定義と「拾ってはいけないもの」（実際に働いている「しかし」「こそ」、
読者への問いかけ、次の議論を開く仮説的な見立て、描写の山場の常体）、および
「事実・引用・固有名詞・数値を変えない」「修正の規模は問題の規模に合わせる」という制約を置いています。
リポジトリの `.claude/skills/nihongo-suikou/SKILL.md` と同じ基準です。基準を変えるときはこの定数を直します。

## データの置き場所

- 原稿は **Artifact のデータベース**（`meta/book` と `sections/sNNN`）にあり、このリポジトリには入っていません。
- 節ごとに `heading` / `body` / `original` / `findings` を持ちます。編集すると自動保存されます。
- データベースが使えない場合は、その端末の localStorage に退避します。

## 使っている capability

`sample`（チェックと修正案）、`db`（原稿の保存）、`downloads`（書き出し）。

## 公開しなおすとき

```
Artifact ツールで index.html を同じ URL に再公開する（url: https://claude.ai/artifact/PjsxaeZAkhhhzrHmLjTJnc）
```
データベースの中身は公開しなおしても消えません。
