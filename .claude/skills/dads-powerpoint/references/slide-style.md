# PowerPoint用スタイルガイド

## 公式仕様と応用値

| 項目 | 同梱DADS文書にある根拠 | このスキルのスライド用設定 |
| --- | --- | --- |
| 配色 | 色相と階調から用途に合うキーカラーを選ぶ | 白地＋Blue-900を既定とする。青は公式必須色ではない |
| 書体 | Noto Sans JP、Noto Sans Mono。OS標準書体も排除しない | 日本語にNoto Sans JP、未導入なら利用可能な代替書体 |
| 太さ | Normal 400、Bold 700 | 通常本文400、見出し・限定的な強調700 |
| 文字サイズ | Web本文は原則16 CSS px以上 | 投影用本文22pt。Webの16pxを12ptへ機械的に変換しない |
| 行間 | 読み物本文は少なくとも1.5倍を推奨、見出し等は用途別 | 本文1.5倍、見出し1.4倍。単独ラベルは1.2倍を目安 |
| 余白 | 絶対的な間隔値はなく、8 CSS pxを一般例として紹介 | 8/16/24/32/48/64/80pxの段階。関連情報ほど近接させる |
| 列 | 1列・12列など。原則、本文文字サイズの2倍のガター | 内部整列にグリッドを使い、本文2列の間隔は64px |
| 画面比率 | ブラウザの画面幅に応じた設計 | 16:9、1280×720px（約13.333×7.5in） |
| 角・影 | 用途に応じて定義・調整 | 通常は直角・影なし。必要な囲みだけ小さな角丸 |

ユーザーの指定や投影環境に応じて応用値は変更できる。DADS原文の数値、公式トークンの値、このスキル独自の役割名を混同しない。

## 配色

HEX値はデジタル庁の公式 `design-tokens` パッケージv2.0.1で確認した値。役割への割当ては本スキルの応用である。

| スライドでの役割 | 公式プリミティブ | HEX |
| --- | --- | --- |
| 背景 | White | #FFFFFF |
| 本文・見出し | SolidGray-900 | #1A1A1A |
| 補助文字・意味のある罫線 | SolidGray-600 | #666666 |
| 薄い面 | SolidGray-50 | #F2F2F2 |
| 純粋な装飾罫線 | SolidGray-200 | #CCCCCC |
| 主色・強調・リンク | Blue-900 | #0017C1 |
| 主色に対応する薄い面 | Blue-50 | #E8F1FE |
| 完了・成功 | Green-800 | #197A4B |
| 完了の薄い面 | Green-50 | #E6F5EC |
| エラー | Red-900 | #CE0000 |
| エラーの薄い面 | Red-50 | #FDEEEE |
| 要確認・警告 | Yellow-1000 | #806300 |
| 警告の薄い面 | Yellow-50 | #FBF5E0 |
| 追加のグラフ系列 | Green-900 / Purple-800 / Orange-900 | #115A36 / #5C10BE / #AC3E00 |

色の使い分けは各スライドの目的に絞る。補助色を全部使う必要はない。警告文字は淡い黄色地でも読めるYellow-1000を採用する。Yellow-900とYellow-50の組合せは4.5:1を満たさないため、そのまま文字に使わない。単純な二色の判定はヘルパーの `contrastRatio` で行える。写真や透過色がある場合は実際に合成された背景も確認する。

テキストは全サイズで4.5:1以上、重要な境界・アイコン・グラフは隣接色との3:1以上を確保する。#CCCCCCの薄い罫線を、読解に不可欠な唯一の境界として用いない。薄い目盛線には高コントラストの値ラベルを組み合わせる。状態・系列を色のみで区別しない。

## 文字サイズと配置

数値は**PowerPointのpt**。Artifact Toolの `fontSize` には4/3倍のpxで渡す。

| 用途 | 既定pt | 作図時px | 適用の目安 |
| --- | ---: | ---: | --- |
| 表紙 | 48 | 64 | 長ければ意味の切れ目で意図的に2行にする |
| ページ見出し | 36 | 48 | 基本1行。無理なら短縮・見出し領域の再設計 |
| 中見出し | 24 | 32 | 列・図表の小見出し |
| 本文 | 22 | 29.33 | 通常はこれより縮めず再構成 |
| 表・図表ラベル | 20 | 26.67 | 行列数が多い場合は分割を優先 |
| 補足説明 | 16 | 21.33 | 本文と分けた短い注記 |
| フッター・出典 | 14 | 18.67 | 判断条件や本文をここへ押し込まない |
| 重要数値 | 56 | 74.67 | 単位・比較基準を近くに置く |

日本語を空白文字で字割りしない。左揃えを基本にし、数値は同じ桁・小数点・単位で揃える。本文の自動縮小は無効にし、句読点や助詞が不自然に孤立した行は文章か幅を修正する。

標準フレームは左右64px、上48px。本文を184px付近で開始し、624pxまでに収め、フッターは664px付近とする。2行見出しなどの場合は本文開始位置を下げて再配分する。2列の本文間隔は64px、短いラベルだけの列では32px程度も使える。

これらは情報の整理を助ける目安であり、画面を埋めるノルマではない。題材に応じて全幅グラフ、縦方向の流れ、左右比較などに変える。
