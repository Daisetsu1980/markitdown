# 推敲前後の実例集

出典：ある新書原稿の推敲前稿と推敲後稿。すべて実物です。判断に迷ったとき、似た型を探して使ってください。

## 目次

1. 構成と見出し
2. 論の運び
3. 文のつなぎ方
4. 文末
5. 語の選び方
6. 表記

## 1. 構成と見出し

**見出しを問いのかたちにする**

- 前：曖昧になるスポーツの境界線
- 後：どこまでがスポーツなのか

- 前：スポーツは「強さ」を創造するためにある――川谷茂樹のスポーツ哲学
- 後：「強さ」は試合の前にあるのか――川谷茂樹のスポーツ哲学

- 前：本質へどう近づくのか――言葉のルールから、事物のしくみへ
- 後：「本質」とは何か――言葉のルールから事物のしくみへ

**副題を主張にする**

- 前：スポーツは何のためにあるのか：はじめてのスポーツ哲学
- 後：スポーツは何のためにあるのか――不合理な遠回りの哲学

---

## 2. 論の運び

**問いを先に置いてから答えさせる**

- 前：そこで川谷は、そもそも強さを試合の前に求めること自体を退けます。「あらかじめ強い者が、試合に勝つ」のではない。「試合に勝った者が、強い」のだ、と。
- 後：この問いに対して、川谷は「あらかじめ強い者が試合に勝つのではなく、試合に勝った者が強いのだ」という逆転の発想で答えます。

**批判の前に譲歩を挟む（推敲で新しく足された段落）**

- 後：もちろん、川谷自身も筋肉や心肺機能といった「能力の素材」が試合前に存在することは認めています。しかし彼のいう「素材」には、筋力や持久力に加えて、選手が日々の鍛錬によって競技専用に培ってきた技術や戦術眼までもが区別なく含まれているように見えます。

**条件を足して正確にする**

- 前：たとえば三角形であれば、例外なく「内角の和が180度になる」という性質をそなえています。
- 後：たとえばユークリッド平面上の三角形なら、例外なく「内角の和が180度になる」という性質を備えており、これは三角形であるかぎり必ず当てはまる必然的な性質です。

- 前：水の透明さも、沸点も、氷になったときの膨張も、すべてこの分子構造の性質から説明できるようになる。
- 後：水の透明さも、沸点も、氷になったときの膨張も、この分子構造を手がかりに、温度や圧力といった条件と合わせて説明できるようになる。

**結論では言い切る**

- 前：こうして見てくると、本章の冒頭で掲げた「設計者がいなくても、そこに目的は宿るのか」という問いの答えが、少しずつ見えてきます。
- 後：ここまでの議論を踏まえれば、冒頭で立てた「設計者がいなくても、そこに目的は宿るのか」という問いへの答えは、もはや明らかでしょう。

**例を絞る**

- 前：近所の公園でキャッチボールをする親子の姿や、ゲートボールを楽しむお年寄りたちの営みはどう映るのか。あるいは、勝敗や相手を打ち負かすことよりも、「道」としての自己修養を重んじる武道の実践は、この体系のどこへ分類されるのでしょうか。
- 後：公園でキャッチボールをする親子や、ゲートボールを楽しむお年寄りたちのプレイは、この理論の射程から大きく外れています。

**対立を畳んで終える**

- 前：……「合否」や「勝敗」というかたちをとって現れたものなのです。
- 後：……「合否」や「勝敗」として現れたものにほかならず、「測定か、創造か」と二者択一で問うこと自体が、この種の制度の実像を見誤らせるのです。

## 3. 文のつなぎ方

**「。しかし」→「〜が、」**

- 前：スーツが書いた『キリギリスの哲学』は、対話篇という、一風変わった体裁の本です。しかし中身は本格的で、出版から半世紀が経った今なお、標準理論と呼ばれるほどの影響力を保ち続けています。
- 後：スーツの著書『キリギリスの哲学』は、対話篇という異色の哲学書です。しかしその議論は緻密であり、出版から半世紀が経った今も、スポーツ哲学の「標準理論」として君臨しています。

（※この例では「しかし」が残っている。「しかし」自体は減っていない。減ったのは「けれども」「ところが」「だとすれば」で、逆接は「しかし」と「〜が、」の二つに集約された。）

**連用中止でつなぐ**

- 前：パリー自身、この点についてはよく自覚していました。彼は批判に対して、自分が定義しようとしているのは「スポーツ一般」ではなく「オリンピック・スポーツ」なのだとはっきり認めています。
- 後：パリー自身もこの点は自覚しており、批判に対して、自分が定義しようとしているのは「スポーツ一般」ではなく「オリンピック・スポーツ」なのだと認めています。

**「のに」で一文に収める**

- 前：ボールを遠くへ飛ばしたいなら、静止したボールを打つほうが、あるいは自分で放り投げたボールを打つほうが、はるかに簡単です。ただでさえ難しいのに、相手が全力で投げ込んでくる速いボールを打ち返すという、いっそう困難な道をわざわざ選んでいる。
- 後：ボールを遠くに飛ばしたいなら、静止したボールを打つか、自分でトスしたボールを打つほうがはるかに簡単なのに、相手が全力で投げた速球を打ち返すという困難を、わざわざ選んでいるわけです。

**段落の頭に橋を架ける**

- 前：もし、さきほどの宇宙人から「……」と問われたら、私たちはどう答えるでしょうか。
- 後：そこでもし、さきほどの宇宙人から「……」と問われたなら、私たちはどう答えるでしょう。

**段落を前の話題の続きとして起こす**

- 前：スポーツが歴史の深層に根ざしていることは、疑いようのない事実です。古代ギリシアのオリンピアでは……
- 後：この熱狂は、今に始まったことではありません。古代ギリシアのオリンピアでは……

**主語を人物に返す**

- 前：ただ走る速さを競うにしても、身体をぶつけ合って力を比べるにしても、かならず「やってはいけないこと」が事細かに定められているようです。表層的なルールの違いを一枚一枚剥がしていけば、やがて奇妙な共通構造が浮かび上がってきます。
- 後：ただ走る速さを競うにしても、体をぶつけ合って力比べをするにしても、そこには必ず「やってはいけないこと」が細かく定められているようです。ついに宇宙人は、表面的な差異を超えて、それらすべてに共通する一つの構造が存在していることに気がつきました。

## 4. 文末

**敬体に寄せる**

- 前：……いっそう困難な道をわざわざ選んでいる。
- 後：……という困難を、わざわざ選んでいるわけです。

**常体を描写の山場に配る（逆方向の直し）**

- 前：しかも、うまく打ち返したあとは、なぜか決まって反時計回りに走り出すのです。
- 後：しかも、うまく打ち返したあとは、決まって反時計回りに走り出す。

**ヘッジを削る**

- 前：では、内角の和が180度になることは、三角形の本質なのでしょうか。おそらく、そうではないでしょう。
- 後：では、「内角の和が180度になること」は三角形の本質なのでしょうか。決してそうではありません。

**進行実況を削る**

- 前：さて、ここまで来て、ようやく本書の最初の問いに戻ることができます。
- 後：ようやく本書の最初の問いに戻ることができます。

**気配りの一文を落とす**

- 前：これは誠実な態度ですし、特定のグループに共通する特徴を取り出す作業そのものに、なんら問題はありません。ただ、そうであれば、パリーの定義は……
- 後：しかし、そうであるなら、彼の定義は……

## 5. 語の選び方

**説明句を一語に**

- 前：一風変わった体裁の本です → 後：異色の哲学書です
- 前：長くて妙な形をした棒を力いっぱい振りかぶって → 後：風変わりな棒を振りかぶって

**像のある動詞に**

- 前：周囲を取り巻く何万人もの人びとが一斉に立ち上がり、激しい怒りをあらわにするにちがいありません。
- 後：観客席から一斉に怒号が飛ぶはずです。

- 前：宇宙人にとっては、もはや理解の範疇を超えています。
- 後：宇宙人は完全にお手上げです。

その他：片付ける→切り捨てる／捉えきれていません→掴みきれてはいません／まじめな研究→本格的な探究／問題は片づいた→議論は決着した／解決できない→片のつかない／行き来→交流

**副詞を削り、情報を入れる**

- 前：はるか遠くの星からやってきた宇宙人が、ふと好奇心に駆られて、地球の競技場をのぞき込んだとしましょう。彼らの目に飛び込んでくるのは、広々とした芝生の上で、22人もの人間がたった一つのボールをすさまじい勢いで奪い合っている光景です。
- 後：はるか遠くの星からやってきた宇宙人が、好奇心に駆られて、地球の競技場をふとのぞき込んだと想像してみてください。彼らの目に飛び込んでくるのは、22人の人間が、広々とした芝生の上で、たった一つのボールを奪い合っている光景です。

**人名にフルネームと肩書き**

- 前：歴史家のホイジンガは『ホモ・ルーデンス』（一九三八年）で
- 後：歴史家のヨハン・ホイジンガは『ホモ・ルーデンス』（1938年）で

- 前：ジェイムズ・キーティングでした。
- 後：実存主義の哲学者であったジェイムズ・キーティングでした。

**年代を具体に**

- 前：一九九〇年頃から、ドーピングや行きすぎた商業主義が、競技の現場を揺さぶりはじめます。
- 後：その後、1980年代後半になると、競技の現場でドーピングや行きすぎた商業主義が目立つようになり、スポーツそのものへの信頼が揺らぎはじめます。

## 6. 表記

**出典を地の文から外す**

- 前：eスポーツの選手は常人離れした反射神経を競い合っていますし、過酷なトレーニングで技術を磨き上げてもいます〔Naraine 2021, pp. 35-36, 39-41。注：Naraineは、eスポーツが競技者の訓練、反応速度、専門的スキル、観客市場を備えた制度化された競技実践として発展していることを確認する〕。
- 後：たしかに、eスポーツの選手たちは人間離れした反射神経を競い合い、過酷なトレーニングで技術を磨いています。

**数える語を漢数字に**

- 前：ひとりが猛スピードでボールを投げ込み、もうひとりが木の棒で打ち返そうとしています
- 後：一人が猛スピードでボールを投げ込み、もう一人が木の棒で打ち返そうとしています

**引用の入れ子**

- 前：「……つまり、「相手の卓越性を消す」ことなくして……」
- 後：「……つまり、『相手の卓越性を消す』ことなくして……」

**「なか」をひらく**

「歴史のなか」「制度のなか」「議論のなか」はかな。物理的な内部を指すときだけ「中」。
