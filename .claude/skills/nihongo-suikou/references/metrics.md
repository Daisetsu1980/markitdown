# 推敲前後の数値

出典：ある新書原稿の推敲前稿（85,445字／1,549文）と推敲後稿（81,430字／1,348文）の全文集計。12字以下の断片と表組みの行は除外。語の出現率はすべて1,000文あたりに正規化。

これは目標値ではなく、参照点です。原稿の性格が違えば適正値も違います。仕上がりがこの表から大きく外れているときに、なぜ外れているのかを自分に問うために使ってください。

## 文の形

| 指標 | 前 | 後 |
|---|---|---|
| 文の数 | 1,549 | 1,348（−13%） |
| 一文の平均字数 | 54.7 | 60.1 |
| 一文の中央値 | 50字 | 55字 |
| 上位10%の長文 | 85字 | 92字 |
| 30字未満の短い文 | 15.4% | 10.5% |
| 一文あたりの読点 | 1.83 | 1.92 |
| 常体まじりの文 | 18.3% | 10.3% |
| 同じ語尾の連続 | 26.1組/1,000文 | 20.4組/1,000文 |

文が長くなっても読点はほとんど増えていません。息継ぎを増やして長くしたのではなく、関係を示す助詞で接いで長くした結果です。

## 増えた語（1,000文あたり）

| 語・型 | 前 | 後 | 増減 |
|---|---|---|---|
| 〜ており、 | 2.6 | 5.9 | +127% |
| 〜ですが、 | 7.7 | 12.6 | +64% |
| 〜ますが、 | 11.0 | 17.1 | +55% |
| 〜のに | 21.9 | 29.7 | +36% |
| こそ | 33.6 | 43.0 | +28% |
| 「のなか」 | 43.9 | 54.2 | +23% |
| しかし | 39.4 | 40.8 | +4% |

上位三つはすべて、文をつなぐ道具です。文が長くなった中身がこれです。

## 減った語（1,000文あたり）

| 語・型 | 前 | 後 | 増減 |
|---|---|---|---|
| 私たち | 67.1 | 60.1 | −10% |
| 〜ましょう | 18.7 | 15.6 | −17% |
| まったく | 15.5 | 12.6 | −19% |
| ところが | 13.6 | 9.6 | −29% |
| もちろん | 9.7 | 5.9 | −39% |
| だとすれば | 11.0 | 5.9 | −46% |
| まさに | 7.7 | 3.7 | −52% |
| 「の中」 | 36.2 | 16.3 | −55% |
| けれども | 4.5 | 1.5 | −67% |

逆接は「けれども」「ところが」を捨て、「しかし」と接続助詞「〜が、」の二つに集約されました。

## 横ばいのもの（意図的に維持されている）

| 語・型 | 前 | 後 |
|---|---|---|
| 〜でしょうか。（読者への問いかけ） | 114 | 114 |
| 〜のです。 | 148 | 144 |
| しかし | 61 | 55 |

ヘッジは削られましたが、読者への問いかけは削られていません。弱めるのは自分の主張についての確信度だけです。

## その他

- 本文中の出典〔著者 年, pp.〕：41か所 → 1か所
- 「――」：46か所 → 32か所（残ったものはほぼ見出しの副題）
- 「〜のです。」のうち段落の最終文にあるもの：71% → 74%

## 自己点検のための簡易スクリプト

長い原稿を直したあと、機械的に点検したいときは次のような集計が使えます。

```python
import re
t = open("draft.txt").read()
ss = [s.strip() for s in re.split(r"(?<=。)", t) if len(s.strip()) > 12]
print("文数", len(ss))
print("平均字数 %.1f" % (sum(len(s) for s in ss) / len(ss)))
print("30字未満 %.1f%%" % (100 * sum(1 for s in ss if len(s) < 30) / len(ss)))
pol = re.compile(r"(です|ます|ません|でしょう|ましょう|ました|でした)。$")
print("常体まじり %.1f%%" % (100 * sum(1 for s in ss if not pol.search(s)) / len(ss)))
ends = [s[-4:-1] for s in ss]
print("語尾の連続", sum(1 for i in range(1, len(ends)) if ends[i] == ends[i-1]))
print("の中", len(re.findall("の中", t)), "／ のなか", len(re.findall("のなか", t)))
```

数値が外れていること自体は失敗ではありません。外れている理由を説明できないときだけ、直します。
